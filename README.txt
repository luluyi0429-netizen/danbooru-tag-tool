Danbooru 标签过滤工具 v2

推荐：打开同目录的“标签工具安装.html”，把“一键标签”拖到 Chrome 书签栏。
如果书签栏没有显示，按 Ctrl+Shift+B。
进入 Danbooru 的单张图片帖子页后，点击这个书签。

也可以安装 Tampermonkey（篡改猴）扩展，新建脚本，将 danbooru-tag-tool.user.js 的全部内容替换进去并保存。
安装后重新打开或刷新 Danbooru 帖子页，右下角自动显示标签工具。
如果 Tampermonkey 提示需要“允许运行用户脚本”，在 Chrome 扩展详情页开启该选项。

已有 v1 书签的用户：删除旧书签，再从新版安装页拖入“一键标签”。
已有 Tampermonkey 脚本的用户：使用新版脚本替换旧内容并保存，然后刷新帖子页。

默认“去外貌”过滤头发、眼睛、脸部、肤色、体型、身体设定。
“去人物设定”另外过滤人数、角色和作品。
“场景与构图优先”进一步过滤已识别的服装、饰品、表情、动作及画师。
未识别标签默认保留，所以“场景与构图优先”不保证只剩场景标签。
通过“过滤类别”可以逐项调整过滤范围。

默认输出 General，可切换为 General + 角色 + 作品，或全部分类。
“复制过滤结果”和“下载 TXT”输出保留下来的逗号分隔标签。
“复制原始”复制当前范围内的原始分类标签，不受过滤和格式转换影响。
支持原始下划线和转换为空格两种输出格式。

“保留”“已过滤”“原始”页签提供完整预览与分类依据。
逐标签选择“始终保留”“始终过滤”会保存为个人例外，优先于预设和类别开关。
选择“自动”移除该标签的例外。“清空例外”清除全部个人例外。
设置与例外保存在本浏览器 Danbooru 域名下，不跨浏览器同步；清理网站数据会清除记录。
隐私模式或浏览器阻止本地存储时，仍可以过滤，但可能无法保留设置。

本版使用内置精确词典和保守规则，未接入外部 AI API。
标签来自 Danbooru 的帖子标注，不是原作者的 AI 生成提示词。

验证：在本地浏览器模拟帖子接口中，验证过滤、例外保存、复制、下载、失败重试和窄屏布局。
